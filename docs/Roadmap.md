# OpenCRM Mobile Roadmap

**Project:** OpenCRM SuiteCRM Mobile
**Version:** 0.0.1
**Platform:** Flutter
**Backend:** SuiteCRM (QuickCRM REST API)

---

# Vision

Build a modern, fast and user-friendly mobile client for SuiteCRM that
offers a community-maintained client for compatible SuiteCRM deployments.

The application must work on:

- Android
- iOS
- Windows
- Web

Future support:

- Linux
- macOS
